# Book Scraper

أداة Python بسيطة لاستخراج بيانات الكتب من موقع [Books to Scrape](https://books.toscrape.com/) وعرضها في جدول منسق.

## المتطلبات

- Python 3.8 أو أحدث
- مكتبات Python التالية:
  - `requests`
  - `beautifulsoup4`
  - `tabulate`

## التثبيت

```bash
pip install requests beautifulsoup4 tabulate
```

## التشغيل

```bash
python Book.py
```

يعرض البرنامج أسماء الكتب وأسعارها وحالة توفرها، ثم يطبع النتائج في جدول منسق.

## ملاحظات

- يستخدم البرنامج الصفحة الرئيسية لموقع Books to Scrape كمصدر للبيانات.
- هذا المشروع تعليمي ومخصص للتجربة على الموقع التجريبي المذكور.
- يُرجى الالتزام بسياسات الموقع وشروط الاستخدام عند إجراء أي عمليات جمع بيانات.

## الترخيص

هذا المشروع متاح للاستخدام والتعديل لأغراض تعليمية.
